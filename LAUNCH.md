# Launch Checklist

- [ ] favicon present and showing in the browser tab
- [ ] no "made with" or AI-generated tag anywhere
- [ ] privacy policy page live and reviewed by the team
- [ ] terms and conditions page live and reviewed by the team
- [ ] API disclaimer visible on every results view
- [ ] `npm run check` passes
- [ ] backend deployed and the VITE_API_URL set to its public address

## Notes

- Note on college demo: For a college demo the project runs locally and no public deployment is required.
- Note on legal pages: Both the Privacy Policy and Terms and Conditions pages must be reviewed by the team and, if the site collects anything later, updated first.
- Note on favicon fallback: A modern SVG favicon is provided at public/favicon.svg. If legacy browser support for ICO format is required, generate favicon.ico using a standard multi-resolution icon tool.
